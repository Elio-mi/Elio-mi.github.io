# LeetCode 42：接雨水（单调栈与双指针）

## 题目链接

[42. 接雨水](https://leetcode.cn/problems/trapping-rain-water/)

给定一组柱子高度，求下雨后能接到的总水量。下面记录两种 `O(n)` 解法：先理解单调栈，再对比空间更省的双指针。

## 方法一：单调栈

### 思路

栈中保存柱子的下标，并让栈内高度保持**单调递减**。

当遇到一根比栈顶更高的柱子时，说明它找到了一个右边界：

1. 弹出栈顶，它是凹槽的底部；
2. 弹出后新的栈顶是左边界；
3. 当前柱子是右边界；
4. 用左右边界中较低的一侧确定水位，结算这个凹槽。

水量计算为：

```text
宽度 = right - left - 1
高度 = min(height[left], height[right]) - height[bottom]
增加水量 = 宽度 × 高度
```

![接雨水单调栈演示](/assets/img/posts/trapping-rain-water-monotonic-stack.gif)

### 代码

```cpp
class Solution {
public:
    int trap(vector<int>& height) {
        stack<int> st;
        int sum = 0;

        for (int right = 0; right < height.size(); right++) {
            while (!st.empty() && height[right] > height[st.top()]) {
                int bottom = st.top();
                st.pop();

                if (st.empty()) break;

                int left = st.top();
                int width = right - left - 1;
                int boundedHeight = min(height[left], height[right]) - height[bottom];
                sum += width * boundedHeight;
            }
            st.push(right);
        }

        return sum;
    }
};
```

### 为什么它更占内存

对。最坏情况下柱子一直递减，所有下标都会进入栈中，因此额外空间是 `O(n)`；时间仍是 `O(n)`，因为每个下标至多入栈、出栈各一次。

### 复杂度

> 时间复杂度：`O(n)`。每个下标最多入栈一次、出栈一次。  
> 空间复杂度：`O(n)`。最坏情况下栈保存所有柱子的下标。

## 方法二：双指针

### 思路

维护左右指针，以及两侧已经见过的最高墙：

- `leftMax`：左侧最高墙；
- `rightMax`：右侧最高墙。

**谁的最高墙更低，就先结算谁。**

- `leftMax <= rightMax` 时，左侧水位已确定，加入 `leftMax - height[left]`；
- 否则结算右侧，加入 `rightMax - height[right]`。

这种写法把关键关系直接写在判断里，理解起来比比较当前两根柱子更直观。

### 动画演示

![接雨水双指针演示](/assets/img/posts/trapping-rain-water-two-pointers.gif)

### 代码

```cpp
class Solution {
public:
    int trap(vector<int>& height) {
        int left = 0;
        int right = static_cast<int>(height.size()) - 1;
        int leftMax = 0;
        int rightMax = 0;
        int sum = 0;

        // 相遇位置也要检查一次，所以是 <=。
        while (left <= right) {
            if (leftMax <= rightMax) {
                leftMax = max(leftMax, height[left]);
                sum += leftMax - height[left];
                left++;
            } else {
                rightMax = max(rightMax, height[right]);
                sum += rightMax - height[right];
                right--;
            }
        }

        return sum;
    }
};
```

### 边界：只有一根柱子

例如 `[1]`：指针相遇后会进入循环一次，更新 `leftMax` 后加上 `1 - 1 = 0`，结果仍然是 `0`。单根柱子没有左右两堵墙，无法接水。

### 复杂度

> 时间复杂度：`O(n)`。左右指针合起来只会遍历每根柱子一次。  
> 空间复杂度：`O(1)`。只使用 `left`、`right`、两侧最高值和累加器。

## 两种方法对比

| 方法 | 时间复杂度 | 额外空间 | 核心理解 |
| --- | --- | --- | --- |
| 单调栈 | `O(n)` | `O(n)` | 找到右边界时，结算凹槽 |
| 双指针 | `O(n)` | `O(1)` | 谁的最高墙低，先结算谁 |

## 记忆口诀

> 单调栈：右墙一来，结算凹槽。  
> 双指针：谁的最高墙低，先算谁。
